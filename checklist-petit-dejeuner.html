La fiche est lisible et imprimable ici, mais rien ne peut être coché durablement, signé ni enregistré : c'est le cas des aperçus de pièces jointes. Pour vous en servir réellement, ouvrez-la dans Chrome :

  1. Enregistrez ce fichier (et non « ouvrir ») : il arrive dans les Téléchargements.
  2. Ouvrez Chrome, puis tapez cette adresse dans la barre du haut :
    file:///sdcard/Download/
  3. Dans la liste qui s'affiche, tapez sur checklist-petit-dejeuner.html.
  4. Menu ⋮ → Ajouter à l'écran d'accueil, pour la lancer comme une application.
